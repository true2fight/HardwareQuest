## 📌 1. Загальні відомості

- **Назва проєкту:** Навчально-ігровий веб-тренажер «HardwareQuest: Збери свій ПК».
- **Цільова аудиторія:** Учні 8 класів закладів загальної середньої освіти (вік: 13–14 років).
- **Призначення:** Підсумкова або поточна перевірка знань, формувальне оцінювання та інтерактивне навчання в рамках розділу «Апаратне забезпечення ПК» шкільного курсу інформатики.
- **Платформа розгортання:** GitHub Pages (статичний клієнтський хостинг без потреби у серверній частині).

## 🎯 2. Мета та ключові можливості проєкту

1. **Гейміфіковане навчання:** Учні проходять 6 інтерактивних інженерних випробувань із підбором характеристик, класифікацією та побудовою схем.
2. **Точна 100-бальна система та 12-бальна шкільна оцінка:** Максимально можлива кількість балів за проходження всіх завдань дорівнює **рівно 100 балам**. Вони автоматично конвертуються в офіційну оцінку за 12-бальною шкалою навчальних досягнень МОН України (1–12 балів).
3. **Автоматична генерація іменного PDF-сертифіката:** Сертифікат формату **A4 Landscape** із захисними рамками, золотим гербом, унікальним верифікаційним номером (`HQ-2026-XXXX`), підсумковим балом (із 100) та оцінкою. Завантажується одним кліком із назвою файлу: `Сертифікат_[Прізвище_Ім'я].pdf`.
4. **Збереження прогресу (LocalStorage):** Результати учня зберігаються автоматично і не втрачаються при перезавантаженні сторінки.
5. **Синтезований звуковий супровід:** Вбудований синтезатор Web Audio API для миттєвого аудіофідбеку (клік, правильна відповідь, помилка, урочисті фанфари перемоги) з можливістю вимкнення звуку.
6. **Святковий салют (Confetti):** При успішному завершенні квесту активується святковий салют часточок на екрані.

## 🚀 5. Інструкція з розгортання на GitHub Pages

1. Створіть новий публічний репозиторій на [GitHub](https://github.com/new) (наприклад, `hardware-quest`).
2. У терміналі папки проєкту виконайте:
   ```bash
   git remote add origin https://github.com/<ВАШ_ЛОГІН>/hardware-quest.git
   git push -u origin main
   ```
3. У репозиторії перейдіть у **Settings** ➡️ **Pages** (у розділі «Code and automation»).
4. У пункті **Build and deployment** оберіть гілку `main` (папка `/root`) та натисніть **Save**.
5. Зачекайте 1–2 хвилини — сайт буде доступний за адресою:
   `https://<ВАШ_ЛОГІН>.github.io/hardware-quest/`

## 🧪 6. Локальний запуск

- **Варіант 1:** Подвійний клік на файл `index.html` у провіднику файлів.
- **Варіант 2:** Локальний сервер Python у терміналі:
  ```bash
  py -m http.server 8000
  ```
  Відкрийте у браузері: `http://localhost:8000`
