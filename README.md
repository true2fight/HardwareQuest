## 📌 1. Загальні відомості

- **Назва проєкту:** Навчально-ігровий веб-тренажер «HardwareQuest: Збери свій ПК».
- **Цільова аудиторія:** Учні 8 класів закладів загальної середньої освіти (вік: 13–14 років).
- **Призначення:** Підсумкова або поточна перевірка знань, формувальне оцінювання та інтерактивне навчання в рамках розділу «Апаратне забезпечення ПК» шкільного курсу інформатики.
- **Платформа розгортання:** GitHub Pages (статичний клієнтський хостинг без необхідності серверної частини).

## 🎯 2. Мета та ключові можливості проєкту

1. **Гейміфіковане навчання:** Замість нудних одноманітних тестів учні проходять 6 інтерактивних інженерних випробувань із підбором характеристик, класифікацією та побудовою схем.
2. **12-бальна шкала оцінювання:** Автоматичний перерахунок набраних балів у шкільну 12-бальну оцінку з визначенням рівня досягнень (Високий, Достатній, Середній, Початковий) та педагогічним фідбеком.
3. **Автоматична генерація іменного PDF-сертифіката:** Сертифікат формату **A4 Landscape** із захисними рамками, унікальним верифікаційним номером (`HQ-2026-8A-XXXX`), оцінкою, датою та лінією для підпису вчителя інформатики. Завантажується одним кліком із правильною назвою файлу: `Сертифікат_[Прізвище]_[Клас].pdf`.
4. **Збереження прогресу (LocalStorage):** Учень не втратить результати при випадковому перезавантаженні сторінки або перемиканні вкладок браузера.
5. **Звуковий супровід:** Вбудований синтезатор звуків (Web Audio API) для миттєвого аудіофідбеку (клік, правильна відповідь, помилка, урочисті фанфари перемоги) з можливістю вимкнення звуку.
6. **Анімації та святковий салют (Confetti):** При успішному проходженні квесту запускається святковий феєрверк частинок.
7. **Зручний експорт звіту:** Кнопка «Копіювати звіт для вчителя» формує відформатований текст для швидкої відправки у Viber, Telegram чи Google Classroom.

## 🕹️ 3. Тематичні модулі тренажера

| Модуль | Назва теми | Ігровий формат | Що вивчається |
|---|---|---|---|
| **Модуль 1** | **Процесор та його характеристики** | Інтерактивний конфігуратор + вікторина | Cores (ядра), тактова частота (GHz), кеш-пам'ять L1/L2/L3, сокет (Socket), TDP. Підбір CPU під 3 задачі: офісний ПК, геймерський комп'ютер, дата-сервер. |
| **Модуль 2** | **Пристрої збереження інформації** | Drag-and-Drop сортування + драбина швидкості | RAM vs ROM, HDD, SSD (SATA, NVMe), USB-флеш, оптичні диски DVD. Енергозалежність (Volatile vs Non-Volatile). Порівняння реальних швидкостей читання/запису. |
| **Модуль 3** | **Пристрої введення інформації** | «Детектив заліза» (ситуаційні кейси) | Клавіатура, миша, планшетний сканер, студійний мікрофон, веб-камера, графічний планшет зі стилусом, сенсорний екран, авіаційний джойстик. Класифікація за типом вхідних даних. |
| **Модуль 4** | **Пристрої виведення інформації** | Встановлення відповідностей (Matching pairs) + бліц-тест | Монітори (144Hz, 4K, IPS), лазерний принтер (тонер), струменевий фотопринтер (рідке чорнило), 3D-принтер (пластик PLA/ABS), широкоформатний плоттер (А0/А1), мультимедійний проектор, акустика 5.1. |
| **Модуль 5** | **Мережеві пристрої** | Інженерний конструктор топології мережі | Оптоволоконний модем (ONT) ➡️ Маршрутизатор (Роутер) ➡️ Комутатор (Свіч) ➡️ Робочі місця учнів (NIC) + Wi-Fi адаптер/точка доступу для гаджетів. |
| **Модуль 6** | **Види сучасних комп'ютерів** | Експертний консиліум замовлень | Настільний ПК (Десктоп), Ноутбук, Моноблок (All-in-One), Планшетний ПК, Смартфон, Сервер (робота 24/7), Суперкомп'ютер (PetaFLOPS). Визначення за сферою використання. |

## 💻 4. Технологічний стек (Tech Stack)

Проєкт виконано повністю на клієнтській стороні (Client-Side), що гарантує миттєве завантаження та безкоштовне розміщення на будь-якому статичному хостингу:

- **HTML5:** Семантична розмітка, ARIA-атрибути для доступності, гнучка структура екранів.
- **CSS3:** Сучасний футуристичний дизайн у стилі Cyber Tech / Gaming з темною темою, неоновими акцентами, скляними ефектами (Glassmorphism), CSS Grid & Flexbox, повна адаптивність (від мобільних 375px до моніторів 1920x1080).
- **JavaScript (ES6+):** Модульна архітектура, обробка подій, підтримка HTML5 Drag & Drop та сенсорного клік-керування, збереження у LocalStorage.
- **Web Audio API:** Апаратна синтезація звукових частот прямо в браузері (без зовнішніх mp3/wav файлів, нульовий мережевий трафік, 100% надійність).
- **html2pdf.js (jspdf + html2canvas):** Клієнтська генерація векторного A4 PDF-сертифіката з підтримкою рендерингу кирилиці.
- **Векторна графіка (SVG):** Усі 30+ зображень комплектуючих створені у чистому форматі SVG, що забезпечує ідеальну чіткість на Retina-дисплеях та миттєве завантаження сайту менше ніж за 1 секунду.
